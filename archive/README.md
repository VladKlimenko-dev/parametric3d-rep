# Исторические архивы ядра

11.11.2026 по запросу владельца удалены все 16 файлов `kernel_k*.zip` из текущего дерева репозитория. Остальные файлы и история Git не переписывались.

Исторические упоминания этих архивов в CHANGELOG и VERSIONS относятся к прежним состояниям репозитория. Для старой версии используйте соответствующий коммит; удаление из `main` не удаляет ZIP-объекты из прежних коммитов и не уменьшает автоматически размер полной истории клона.

Новые дубли ядра в виде `kernel_k*.zip` не следует добавлять в Git. Исходники версионируются коммитами; при необходимости отдельная поставка оформляется как release artifact.
