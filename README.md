# Parametric3D

Параметрическое CAD-приложение на C#/.NET 8 и Avalonia 12. Геометрическое ядро, модель документа и интерфейс находятся в одном основном проекте `src/Parametric3D.csproj`; отдельная библиотека `Parametric3D.Fea` из другой работы сюда не добавлена.

## Навигация

- [Карта сущностей и процессов](src/ARCHITECTURE.md): фактическое устройство ядра, модели, приложения и расчётной сетки.
- [Сверка требований и замечаний](docs/REQUIREMENTS_REVIEW.md): что реализовано, что частично и что требует проверки.
- [Отчёт обновления из src.zip](docs/SYNC_AUDIT_2026-11-11.md): изменения, очистка, результаты и ограничения проверки.
- [Открытые задачи](src/docs/release/BACKLOG.md): подробные замечания пользователя; старые отметки выполнения не являются свежим тестом.
- [Устройство приложения](src/App/README.md) и [стратегическая цель](src/docs/release/STRATEGY_AI_DESIGN.md).

## Сборка

```sh
dotnet build src/Parametric3D.csproj -c Release
dotnet run --project src/Parametric3D.csproj -c Release -- --sample
```

На Windows можно использовать `run.bat` или `run.ps1`. Скрипты по умолчанию обновляют клон; для проверки именно текущего checkout используйте `-NoPull`.

## Ограничения поставки

Новый код резьбы читает `threads_db.json` и `threads_table.csv`, но эти таблицы не входят в переданный `src.zip` и не найдены среди файлов исходного репозитория. Косметическая резьба без табличного типа предусмотрена; табличную резьбу и настоящий вырез нельзя считать комплектными без исходных таблиц и отдельной проверки.

Исторические проценты готовности, время расчёта и результаты корпусов в документах относятся к указанным там версиям. Они не заменяют воспроизводимую проверку текущего кода.
