# Parametric3D: исходники

Это C#/.NET 8 CAD-приложение с интерфейсом Avalonia 12, а не прежняя оболочка WinForms. Актуальная навигация по репозиторию находится в [корневом README](../README.md), устройство подсистем в [карте проекта](ARCHITECTURE.md), интерфейс в [App/README.md](App/README.md).

## Сборка из корня репозитория

```sh
dotnet build src/Parametric3D.csproj -c Release
dotnet run --project src/Parametric3D.csproj -c Release -- --sample
```

Пакеты восстанавливаются из NuGet. Для команд и параметров поставки смотрите [инструкцию передачи](docs/release/HANDOFF_NEXT_BRANCH.md), а для проверенных результатов именно этого обновления [отчёт сверки](../docs/SYNC_AUDIT_2026-11-11.md).

## Документация

Старые `HANDOFF.md` и `SOSTOYANIE.md` удалены из текущего дерева как устаревшие инструкции. Незакрытые обязательства и технические уроки перенесены в [реестр сверки](../docs/REQUIREMENTS_REVIEW.md); прежние тексты остаются в истории Git.

Документы `docs/release` включают планы и исторические отчёты разных этапов. Их исходные числа и отметки выполнения нельзя считать свежей проверкой текущего архива; при расхождении сначала смотрите отчёт сверки и исходный код.
