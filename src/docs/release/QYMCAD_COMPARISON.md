# QymCAD и Parametric3D: сравнение (k119, 2026-10-27)

Источник по QymCAD — репозиторий github.com/QymIs-Tech/QymCAD (ветка main на 26.10.2026, версия 0.1.1): README,
встроенная справка `docs/help`, исходники крейтов `qymcad-meshfit` и `qymcad-kernel/src/recognise.rs`. Код QymCAD
под AGPL-3.0 — из него ничего не переносилось: разобран только подход, перевод сетки в Parametric3D написан заново.

## 1. Общее

| | QymCAD | Parametric3D |
|---|---|---|
| Ядро | OpenCASCADE 7.9.3 (B-rep, то же, что у FreeCAD) | собственное ядро (C#): аналитическая булева, скругления, NURBS |
| Язык, интерфейс | Rust, egui + wgpu | C#/.NET 8, Avalonia + OpenGL |
| Объём кода | ≈ 320 тыс. строк Rust, 19 крейтов | ядро + приложение; ≈ 670 проверок в наборах (с мутациями) |
| Платформы | Windows, Linux (AppImage), macOS (без подписи Apple) | Windows (проверяется), Linux — сборка и проверки в среде разработки |
| Лицензия | AGPL-3.0 (производные — тоже открытые) | закрытая, своя |
| Языки | русский, украинский, казахский, английский | русский, английский |
| Формат документа | `.qcad`, меняется без совместимости (скрипт перевода) | `.p3d`/`.p3a`, версия формата и строгое чтение |
| Зрелость | 0.1.1, «обновляется ежедневно», CAM не работает | k119; ядро проверяется наборами allA/allB/UI с мутациями |

## 3. В чём QymCAD лучше

- Промышленное ядро OCCT: многолетняя отладка булевых, скруглений, сшивки; обмен STEP с другими системами проверен
  миром.
- Кинематика сборки (приводы, пределы, степени свободы), проверка пересечений, библиотека изделий.
- Форматы обмена: 10 форматов чтения и записи (сетки печати и визуализации, DXF/SVG для эскизов).
- Резьба настоящим профилем; три платформы с установочными пакетами; 4 языка.
- Распознавание сетки шире по видам поверхностей: свободные формы (B-сплайн по точкам), винтовые (резьба, шнек,
  пружина).

## 4. В чём Parametric3D лучше

- Своё ядро: полный контроль над точностью и поведением (точная аналитическая булева, точные объёмы и центры масс,
  проверка тела по уровням геометрии), без зависимости от OCCT и его сборки.
- Окружение FreeForm (NURBS), смешения, исполнения, многоуровневые параметры с путями к размерам, поверхности.
- Эскизник в духе Creo: слабые и сильные размеры, ссылки на рёбра тела, разрешение противоречий.
- Анализ: масса и инерция, зебра, кривизна, проверка и лечение тела; сечение вида.
- Совместимость документа (версия формата, строгое чтение) — QymCAD меняет формат без совместимости.
- Перевод сетки в тело (раздел 6): выравнивание по замыслу, точные касания, допуски рёбер, правимая операция.

## 5. Проблемы

| QymCAD | Parametric3D |
|---|---|
| формат документа без обратной совместимости | ядро молодое: сложные случаи уходят в многогранный путь (двойные стенки k117) |
| CAM в составе, но не работает | нет чертежей (в работе), нет кинематики и проверки пересечений |
| macOS без подписи Apple; сборка ядра из исходников обязательна (флаги OCCT) | проверено на Windows и Linux-среде разработки; установочных пакетов нет |
| распознавание: что не легло в поверхность, остаётся треугольниками внутри тела; большие сетки — «десятки секунд на сотню тысяч треугольников» | распознавание: нет свободных форм и винтовых поверхностей (такие места — плоскими гранями); шумные сканы — только с большим допуском |
| AGPL: закрытая производная невозможна | скорость перестроения больших деталей (деталь пользователя — 32 с) |

## 6. Сетка → точное тело

### Как у QymCAD (`qymcad-meshfit`, `recognise.rs`)

1. Подготовка: слияние вершин (10⁻⁶ диагонали), треугольники без площади и повторы долой, обход согласуется,
   нормали наружу по знаку объёма, соседи и граница.
2. Области растут вместе с поверхностью: затравка пробует плоскость, цилиндры (ось — по нормалям затравки и каждого
   соседа), конусы, сферы; берётся покрывшая больше (кривая — в 1.5 раза больше плоскости). Допуск — 10⁻⁵ диагонали,
   нормаль — 10° в центре описанной окружности.
3. Слияние соседей, вместе лежащих на одной поверхности (так собираются торы из полос); соосные полосы; винтовые
   поверхности (резьба, шнек), пружина; свободные формы — один B-сплайн на мозаику.
4. Границы областей, вершины (наименьшие квадраты на поводке), кривые рёбер: прямая, окружность, эллипс, иначе —
   ломаная по точкам сетки.
5. Тело собирает OCCT (грани на поверхностях, сшивка); грань, взявшая не тот кусок поверхности, отбрасывается, её
   область остаётся треугольниками; тело строится дважды.

### Как сделано у нас (k119, `src/Kernel/MeshFit`)

Тот же каркас (подготовка → области → границы → кривые → тело), и улучшения:

| | QymCAD | Parametric3D |
|---|---|---|
| ось конуса | Плюккер по прямым нормалей; на полосе в один ряд треугольников уходит | наименьший собственный вектор **центрированного** разброса нормалей граней (у конуса n·a постоянна), центр — совместно по всем высотам |
| цилиндр скругления | ось по паре нормалей, окружность — по кусочку в два кольца | окружность — по вершинам пары «затравка + сосед»: кусочек заходит на касательную плоскость и смещал радиус (R3 → 3.49) |
| ложные цилиндры | через вершины двух соседних плоских стенок всегда проходит цилиндр | кривизна доказывается гранями сетки: ≥ 3 разных плоских кусочка, ни один > 60% площади |
| выравнивание по замыслу | нет (кроме соосности при сегментации) | оси и нормали — к осям координат и друг к другу; соосность; радиусы, смещения плоскостей, координаты осей и вершин конусов — к круглым значениям; касание плоскостей и кривых — точно; ни один шаг не «покупается» точностью (СКО не больше ×3) |
| вершины у касающихся граней | поводок 4× отхода | поводок √(2·допуск·R) |
| рёбра «прочее» | ломаная по точкам сетки | ломаная по пересечению обеих поверхностей, сгущённая до допуска |
| целые сфера и тор | — | делятся на грани (сфера — 2, тор — 4: половина тора по экватору неоднозначна) |
| сборка тела | OCCT, сшивка; несошедшееся — треугольники внутри тела | текст STEP → тот же импорт, что для чужих файлов; допуски рёбер измеряются (tolerant edges); проверка тела и объёма |
| если не вышло | куски сетки внутри тела | цепочка: точно → плоскими гранями → строго плоскими (тело всегда годное) |
| хранение | узел «Распознанное тело», сетка поглощается | операция «Импорт STL»: треугольники, настройки и итог в документе; правка — другие настройки, без повторного файла |
| интерфейс | отдельный инструмент после импорта | галочка «Преобразовать в точную геометрию» в окне импорта; допуск, единицы файла, выравнивание |
| скорость | «десятки секунд на 100 тыс. треугольников» (их справка) | 624 тыс. треугольников (куб со 100 отверстиями) — 6 с |
