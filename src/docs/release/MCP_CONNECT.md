# Подключение Claude к Parametric3D (MCP)

k154. Parametric3D содержит сервер MCP (Model Context Protocol), открытого протокола подключения ассистентов к программам.
Claude видит открытый в приложении документ и работает с ним через инструменты: читает дерево операций и параметры, меряет
деталь, делает снимок вида, правит значения. Каждая правка — один шаг отмены в приложении («Claude: …»).

## Как устроено

- Пока Parametric3D открыт, сервер слушает только этот компьютер: `http://127.0.0.1:47853/mcp`, или следующий свободный порт.
- Ключ доступа случайный при каждом запуске. Адрес и ключ лежат в `%APPDATA%\Parametric3D\mcp.json`.
- Для Claude Desktop используется мост: тот же `Parametric3D.exe`, запущенный с параметром `--mcp-stdio`. Окна он не
  открывает и передаёт вызовы запущенному приложению. Если приложение закрыто, Claude получит сообщение «Parametric3D is not
  running».
- Выключить сервер можно переменной окружения `P3D_MCP=0`.

## Claude Desktop

1. В Parametric3D: «Все команды» → «Подключить Claude (MCP)» → «Копировать». В буфер попадёт фрагмент настроек с путём к
   вашему `Parametric3D.exe`.
2. В Claude Desktop: Настройки → Разработчик → Изменить настройки (файл `claude_desktop_config.json`). Вставьте фрагмент:

```json
{
  "mcpServers": {
    "parametric3d": {
      "command": "C:\\путь\\к\\Parametric3D.exe",
      "args": ["--mcp-stdio"]
    }
  }
}
```

   Если в файле уже есть `mcpServers`, добавьте в него только запись `"parametric3d": { … }`.
3. Перезапустите Claude Desktop. В чате появятся инструменты Parametric3D.

## Claude Code

```
claude mcp add parametric3d -- "C:\путь\к\Parametric3D.exe" --mcp-stdio
```

## Инструменты

| инструмент | что делает |
|---|---|
| `get_document` | документ: имя, файл, детали, число операций, ошибки, идёт ли расчёт |
| `list_features` | дерево операций: номер, ключ, имя, тип, сводка, ошибка, подавлена |
| `get_feature` | все значения одной операции: числа (с формулами), флаги, выборы |
| `set_feature_value` | изменить значение операции (`Diameter`, `Radius`, `Side1.Distance`, `ThroughAll`…; число, флаг, выбор или `=формула`) и перестроить |
| `suppress_feature` | подавить или вернуть операцию |
| `get_parameters`, `set_parameter` | параметры документа |
| `rebuild` | перестроить; ошибки, объём, время |
| `get_mass_properties` | объём, площадь, масса, габариты; у тел — уровень гарантии (точное или многогранное) и годность |
| `capture_view` | снимок вида (PNG) |
| `undo`, `redo` | отмена и возврат |
| `open_document`, `save_document`, `export` | открыть, сохранить, экспорт STEP, IGES, STL, OBJ |
