# Иконки приложения: список и требования

Список иконок нового приложения (Avalonia), составлен 2026-10-16 по ТЗ_UI (таблицы наборов Д/ЭС/Ф/СБ, требования UI-01…UI-45) и по возможностям прежнего приложения. Источник данных — `src/App/Assets/icons.tsv`: приложение берёт имена иконок оттуда, и команда без файла иконки показывается текстом — рисовать можно постепенно, по этапам.

## Требования к файлам

- Формат — SVG. Кнопки команд (`*_but.svg`) — сетка 24×24 (`viewBox="0 0 24 24"`), показ 20–24 px. Значки дерева и состояний (`*_ico.svg`) — сетка 16×16 (`viewBox="0 0 16 16"`), показ 16 px; значки состояний ещё и наложением 10 px в углу значка узла.
- Одноцветная часть — чистый чёрный `#000000`: приложение перекрашивает его в цвет текста темы (светлый на тёмной теме, тёмный на светлой). Белые заливки не использовать (пропадут на светлой теме) — фон прозрачный.
- Цветные акценты — только из палитры (`UI_VIEW_PALETTE.md`, «Цвета UI»); они не перекрашиваются. Смысл цветов один во всём приложении:
  - добавление материала — оранжевый `#FF7A1A`;
  - вырез, удаление, ошибка — красный `#EF4444`;
  - предупреждение — янтарный `#F59E0B`;
  - успех, управляющий размер — зелёный `#4ADE80`;
  - опорные элементы (плоскость, ось, точка, СК) — синий `#6EA0FF`;
  - эскиз — жёлтый `#FFD64A`;
  - оси X / Y / Z — `#E5484D` / `#30A46C` / `#3E7BFA`;
  - выбор — синий `#2F8CFF`.
- Линии — 1,5 при сетке 24 (1,25 при сетке 16), концы и стыки скруглённые; без текста и букв (перевод интерфейса), без растровых вставок, без `<style>`, CSS-классов и шрифтов — только контуры.
- Имена — точно как в таблицах; место — `src/App/Assets/Icons/`. Лишние файлы не мешают, недостающие заменяются текстом.
- Кодом рисуются (иконки не нужны): сам куб вида и кольцо компаса, гизмо, ручки операций, стрелки размеров, знаки связей в эскизе на модели, сетка, курсоры.
