## b) Распознавание свободных форм и винтовых поверхностей из STL

- Перевод сетки (k119, `src/Kernel/MeshFit`) сейчас знает плоскость, цилиндр, конус, сферу, тор; прочее — плоскими
  гранями.
- Нужно: B-сплайн по точкам области (свободная форма; наименьшие квадраты с регуляризацией, проверка допуска, рост
  области вместе с поверхностью), винтовые поверхности (резьба, шнек, пружина: ось, шаг, профиль; соосность и круглые
  значения шага — к выравниванию по замыслу).
- Проверки: образцы ядра (резьба винтовым sweep, лофт, NURBS из FreeForm) → STL → перевод: число граней, вид
  поверхностей, ошибка объёма.

## c) Импорт тех же форматов, что у QymCAD

- Сейчас: STEP, IGES, STL. У QymCAD: STEP, IGES, STL, OBJ, PLY, glTF, 3MF, AMF, DXF, SVG (`QYMCAD_COMPARISON.md`).
- Сетки (OBJ, PLY, glTF/GLB, 3MF, AMF) — тем же путём, что STL: «Импорт сетки» с галочкой «Преобразовать в точную
  геометрию».
- DXF, SVG — в эскиз (линии, дуги, окружности, сплайны, полилинии; единицы файла).
- Экспорт тех же форматов — следом.

## d) CAM

- Траектории на виде, имитация съёма, постпроцессоры (G-код: Fanuc, Haas, GRBL, Mach3/LinuxCNC).
