# Палитра вида и UI (Avalonia): тёмная и светлая темы

Этап UI. Цвета вида (OpenGL/Skia) и интерфейса — из одного набора: синий выбора, янтарный наведения, красный ошибки,
янтарный предупреждения, оси X/Y/Z одни и те же в сцене, гизмо, панелях свойств, иконках и дереве операций.

## Правила

- **Ресурсы, а не числа в коде.** Каждый цвет — ресурс темы Avalonia (`ThemeDictionaries`: `Light`/`Dark`) с тем же
  именем, что и стиль вида (`RenderStyles`). Вид берёт цвета из ресурсов текущей темы — смена темы меняет и сцену, и UI.
- **Состояния единые для всех сущностей.** Наведение — янтарный, выбор — синий. Ширина линии при наведении и выборе +1,4 px,
  размер точки +3 px (`HighlightWidthBonus`, `HighlightSizeBonus`). Прозрачность исходного стиля сохраняется.
- **Размеры — в логических пикселях,** масштабируются на DPI экрана. Линии рисуются со сглаживанием, точки — кругом,
  если не указано иное.
- **Полупрозрачные заливки** (предпросмотр, плоскости, гизмо): рисуются после непрозрачных, без записи глубины. Рёбра
  предпросмотра — поверх с проверкой глубины, линия пересечения — без проверки.
- **Светлая тема** — те же оттенки, темнее на 10–25 % (контраст ≥ 3:1 к фону для линий). Белый центр-линии на светлом фоне
  заменён тёмно-серым, жёлтый обрис эскиза — синим.
- **Оранжевый, жёлтый и янтарный разведены:** добавляемый объём — оранжевый (R ≈ 255, G ≈ 122), наведение — янтарный
  (G ≈ 176), ручки операции — жёлтый (G ≈ 214) с тёмной обводкой.

Формат RGBA: `rgba(R, G, B, A)`, R/G/B — 0…255, A — 0…1; рядом `#RRGGBBAA`. Сначала тёмная тема, затем светлая.
