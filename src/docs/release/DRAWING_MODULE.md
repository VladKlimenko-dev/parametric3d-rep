# Чертёж, шаблон листа, перечень (BoM): устройство и иконки

Составлено 2026-10-27 (k118) по замечанию 08:54, п. 12. Это план трёх новых видов документа и список иконок для них.
Иконки — по правилам `UI_ICONS.md`: SVG, сетка 24×24, чистый чёрный перекрашивается под тему, цвета только из палитры,
без текста и букв. Шрифт всего, что попадает на лист, — ГОСТ тип А (GOST_A.TTF, уже встроен).

## 1. Виды документов

| Документ | Расширение | Откуда берёт данные | Главное |
|---|---|---|---|
| Чертёж | `.p3drw` | деталь или сборка из файла (выбор при создании) | листы, виды, размеры, обозначения, основная надпись, таблицы |
| Шаблон листа | `.p3dtpl` | — | формат, ориентация, рамка, основная надпись, таблицы, поля для автозаполнения |
| Перечень (BoM) | `.p3dbom` | **только сборка** из файла | шапка и таблица позиций; строки можно выбирать, удалять, добавлять |

Связь с моделью — по пути к файлу и номеру (Id) элемента, как у ссылок эскиза. Чертёж и перечень пересчитываются при
открытии и по команде «Обновить», если модель изменилась (по отпечатку модели); устаревший вид помечается значком.

## 2. Шаблон листа

- Форматы по умолчанию — ГОСТ 2.301 (ISO 5457): A0 841×1189, A1 594×841, A2 420×594, A3 297×420, A4 210×297, кратные
  (A3×3 и т. п.); ориентация книжная или альбомная (A4 — только книжная по ГОСТ 2.301).
- Рамка — ГОСТ 2.104: поле подшивки 20 мм слева, 5 мм с остальных сторон; ISO 5457 — 20/10 мм и зоны с разметкой.
- Основная надпись — ГОСТ 2.104 форма 1 (первый лист чертежа, 185×55), форма 2 (первый лист текстовых документов
  и перечня, 185×40), форма 2а (последующие листы, 185×15); для ISO — блок ISO 7200 (180×≥ 30).
- Поля надписи — автоматические: обозначение, наименование, материал, масса, масштаб, лист/листов, разработал,
  проверил, организация, изменение и дата (из «Свойств детали» — п. 11 k118: обозначение, наименование, изменение,
  материал, масса, единица учёта, допуски).
- Таблицы шаблона: технические требования (текст), таблица изменений, таблица отверстий, перечень на поле чертежа.
- Стандарт по умолчанию — ЕСКД (ГОСТ 2.104/2.301/2.304/2.307); переключатель «ЕСКД / ISO / ASME Y14» в шаблоне меняет
  рамку, надпись, проекционный метод (первый угол — ЕСКД/ISO, третий — ASME) и вид знаков.

## 3. Чертёж

Лучшее из Creo Drawing и SolidWorks Drawing:

- **Виды**: основной (проекция по выбору плоскости или ориентации), проекционные (тянуть от основного — как в
  SolidWorks), 3D-вид (аксонометрия, изометрия, диметрия ГОСТ 2.317), разрез и сечение (линия разреза на виде),
  выносной элемент (круг на виде), местный разрез, разрыв, вспомогательный вид (по ребру), повёрнутый вид.
- Стиль вида: видимые линии, невидимые штрихом, тонирование; линии перехода (касательные рёбра) — вкл/выкл.
- Масштаб вида — из ряда ГОСТ 2.302 (1:1, 1:2, 1:2,5, 1:4, 1:5, 1:10…; 2:1, 2,5:1, 4:1, 5:1, 10:1).
- **Размеры**: «Показать размеры модели» (размеры эскизов и операций переносятся на подходящий вид — как Creo Show
  Annotations), «Скрыть/показать» выбранные, «Автоматические размеры» (базовые, цепочкой, от базы — как SolidWorks
  Auto Dimension Scheme), ручные (линейный, радиальный, диаметр, угловой, ординатный, фаска), правка размера на чертеже
  меняет модель только для размеров модели (управляющие); чертёжные — справочные.
- **Обозначения**: шероховатость (ГОСТ 2.309), допуски формы и расположения GD&T (ГОСТ 2.308 / ISO 1101 / ASME Y14.5)
  с базами, осевые линии и метки центра (автоматически на отверстиях), выноски с номерами позиций (сборка),
  текст и технические требования, обозначение сварки, резьбы (ГОСТ 2.311).
- **GD&T вкл/выкл**: переключатель слоя обозначений; правка рамки допуска — двойной щелчок (окно: знак, значение,
  модификаторы Ⓜ Ⓛ Ⓟ, базы A/B/C).
- Слои и листы: несколько листов в чертеже, у каждого — шаблон.
- Вывод: PDF (векторный), DXF/DWG (позже), печать.

Устройство: вид = набор проекций рёбер тела (точная геометрия ядра → линии на плоскости вида со скрытием по
глубине), обозначения хранятся отдельно с привязкой к элементам модели (Id ребра/вершины и ориентир на виде), чтобы
после перестроения модели оставаться на месте; потерянная привязка — обозначение красным, как у эскиза.

## 4. Перечень (BoM)

- Создаётся только из сборки (выбор файла сборки при создании; из детали — недоступно).
- Шапка: название, обозначение (номер) сборки, номер изменения и дата.
- Таблица: № (позиция), обозначение / наименование, описание, количество, единица учёта, материал.
- Строки собираются из сборки (одинаковые детали — одна строка с количеством; подсборки — раскрыть/свернуть);
  пользователь выбирает строку (подсветка, как в окне параметров), удаляет и добавляет строки (прочие изделия,
  материалы — строки без модели).
- Вид по ЕСКД — спецификация ГОСТ 2.106 (разделы «Документация», «Сборочные единицы», «Детали», «Стандартные
  изделия», «Прочие изделия», «Материалы»), основная надпись форма 2/2а; по ISO — таблица ISO 7573.
- Номера позиций перечня и выносок на чертеже сборки — общие.
