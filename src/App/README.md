# Приложение Parametric3D (Avalonia)

Новое приложение (с 2026-10-16) по ТЗ_UI и UI_AVALONIA_STAGE: окно — прежде всего вид, минимум рамок, команды — из
одного реестра (кнопки, меню, палитра F, клавиши), выбор без режимов, тёмная и светлая темы из палитры вида.

## Устройство

| Папка | Что |
|---|---|
| `Program.cs`, `App.axaml` | запуск; графика: под Windows по умолчанию ANGLE (OpenGL ES 3 поверх Direct3D 11), WGL — по выбору (`--gl`, `P3D_GL`, «Файл → Графика»); под Linux GLX, затем EGL; журнал запуска, команд и аварийного завершения |
| `Theme/` | цвета оболочки (`Palette.axaml`, тёмная и светлая — по UI_VIEW_PALETTE) и стили кнопок и панелей |
| `Commands/` | реестр команд (`CommandRegistry`), команда (`AppCommand`: имя, группа, иконка, клавиша, синонимы RU/EN), все команды (`StandardCommands`) |
| `Localization/` | язык интерфейса: `Loc.L("строка")` и перевод `Strings.En` (кнопка EN/RU у темы) |
| `Operations/` | операции в правой панели: поля и ссылки (`OpPanel`, `RefField`), живой предпросмотр (`FeatureOp`), выдавливание, вращение, скругление, фаска, вершины, оболочка, отверстие, зеркало, массивы, опорная плоскость, эскиз |
| `Sketching/` | инструменты эскиза (отрезок, прямоугольник, окружность, дуга, эллипс, сплайн, точка, осевая) |
| `Icons/` | иконки пользователя: SVG из `Assets/Icons` (вшиты в сборку), чёрный перекрашивается в цвет темы; нет файла — подпись |
| `Assets/icons.tsv` | список иконок (источник `docs/release/UI_ICONS.md`) — имена, назначение, этап |
| `Services/` | открытый документ (`DocumentSession`: файл, правка одним шагом отмены, длинная правка `BeginEdit/CommitEdit/CancelEdit`, журнал), экспорт, настройки пользователя (`ui.json`: тема, язык) |
| `ViewModels/` | узел дерева модели |
| `Views/` | главное окно, окно параметров (`ParametersDialog`), простые окна вопросов |
| `Viewport/` | 3D-вид (`ModelViewport`: OpenGL Avalonia + движок `src/Render/Engine`; режим эскиза — `ModelViewport.Sketch.cs`), выбор (`Selection`, запасной `ScenePicker` без OpenGL), куб вида (`ViewCube`, UI-45) |
| `Diagnostics/` | кнопка «Тест» (`SelfTest`, `TestParts`: замер скорости и отчёт; `--selftest` — без окна теста), долгие участки потока окна (`UiTimes`), снимки вида и сценарии без человека (`--shot`, `--script`) |

Движок вида — `src/Render/Engine`: `SceneBuilder` собирает сцену из документа (на процессоре, только при изменении),
`SceneRenderer` рисует кадр (MSAA, свет с гаммой, контур силуэта, рёбра постоянной ширины, штрих невидимых линий,
точки, надстройка эскиза) и делает проход выбора видеокартой. Привязки OpenGL — свои (`Render/Gl/GL.cs`), шейдеры —
общее подмножество OpenGL 3.3 и OpenGL ES 3.0.

## Что есть

- Окно: верхняя полоса (меню «Файл», документ и режим, отмена/повтор, журнал, поиск команды, «Параметры», «Свойства» —
  повторный щелчок скрывает, тема, язык EN/RU), дерево модели, вид, правая панель (операция или свойства), строка
  состояния, палитра команд (F).
- Вид: вращение (средняя), сдвиг (Shift+средняя или правая), масштаб к курсору (колесо); панель вида — вписать,
  проекция одной кнопкой, стиль (по умолчанию «тонированный с рёбрами»), «Опорные» со списком что показывать; куб вида
  (UI-45). Выбор граней, рёбер, вершин тела, плоскостей, эскизов — во всех стилях (Shift — добавить, Ctrl — исключить,
  Esc — снять).
- Полоса операций слева и полоса выбора внизу вида с подходящими к выбранному операциями (как в Plasticity).
- Операции в правой панели с живым предпросмотром, «ОК» — один шаг отмены, «Отмена» — как было; правка готовой операции
  двойным щелчком в дереве.
- Эскиз на опорной плоскости или плоской грани: вид по нормали, сетка с привязкой, инструменты построения.
- Параметры по уровням (документ, сборки, детали) — как в Creo.
- Файл: новая деталь, пробная деталь, открыть, последние файлы, сохранить (`.p3d`), импорт STEP/IGES, экспорт (точный
  STEP, STL, OBJ).
- Дерево: глаз детали скрывает всё внутри; свернуть/развернуть всё, включая деталь; ветки не сворачиваются сами.

## Проверки

`tests/ui` (Avalonia.Headless, без экрана): реестр команд и иконки, палитра, отмена/повтор, файл и экспорт, выбор
мышью в виде, куб вида, тема, дерево (видимость и сворачивание), операция в панели, эскиз → выдавливание, параметры по
уровням, язык. Снимки окна под Xvfb — `--shot файл.png --script "команда;pick:0.5,0.5;click:0.4,0.4;ok"` (шаги
выполняются по одному: `pick`/`add`/`hover` — выбор в долях вида, `click` — щелчок инструмента эскиза, `ok`/`cancel` —
кнопки панели операции).
