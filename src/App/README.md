# Приложение Parametric3D (Avalonia)

Новое приложение (с 2026-10-16) по ТЗ_UI и UI_AVALONIA_STAGE: окно — прежде всего вид, минимум рамок, команды — из
одного реестра (кнопки, меню, палитра F, клавиши), выбор без режимов, тёмная и светлая темы из палитры вида.

## Устройство

| Папка | Что |
|---|---|
| `Program.cs`, `App.axaml` | запуск; OpenGL: под Windows WGL (настольный), затем ANGLE (OpenGL ES 3), под Linux GLX, затем EGL |
| `Theme/` | цвета оболочки (`Palette.axaml`, тёмная и светлая — по UI_VIEW_PALETTE) и стили кнопок и панелей |
| `Commands/` | реестр команд (`CommandRegistry`), команда (`AppCommand`: имя, группа, иконка, клавиша, синонимы RU/EN), команды этапов U0–U1 (`StandardCommands`) |
| `Icons/` | иконки пользователя: SVG из `Assets/Icons` (вшиты в сборку), чёрный перекрашивается в цвет темы; нет файла — подпись |
| `Assets/icons.tsv` | список иконок (источник `docs/release/UI_ICONS.md`) — имена, назначение, этап |
| `Services/` | открытый документ (`DocumentSession`: файл, правка одним шагом отмены, журнал), экспорт, настройки пользователя (`ui.json`) |
| `ViewModels/` | узел дерева модели |
| `Views/` | главное окно, простые окна вопросов |
| `Viewport/` | 3D-вид (`ModelViewport`: OpenGL Avalonia + рендер `src/Render`), выбор под курсором (`ScenePicker`, `Selection`), куб вида (`ViewCube`, UI-45), палитра вида |
| `Diagnostics/` | снимки вида и сценарии без человека (`--shot`, `--script`) |

Рендер (`src/Render`) прежний: свои привязки OpenGL (`Render/Gl/GL.cs`) вместо OpenTK.Graphics, шейдеры — общее
подмножество OpenGL 3.3 и OpenGL ES 3.0 (заголовок меняется под контекст).

## Что уже есть (этапы U0–U1)

- Окно: верхняя полоса (меню «Файл», документ и окружение, отмена/повтор, журнал отмены, поиск команды, тема,
  свойства), дерево модели, вид, панель свойств, строка состояния.
- Файл: новая деталь, пробная деталь, открыть, последние файлы, сохранить, сохранить как (`.p3d`), импорт STEP/IGES,
  экспорт (точный STEP, STL, OBJ) с проверкой замкнутости сетки; вопрос о несохранённых изменениях.
- Правка: каждая правка — один шаг отмены (`DocumentSession.Edit`), журнал отмены с переходом к любому шагу (UI-37),
  удаление операций, эскизов и опорных элементов.
- Вид: вращение (средняя), сдвиг (Shift+средняя или правая), масштаб к курсору (колесо), виды и изометрия с плавным
  переходом, вписать (Ctrl+F), перспектива/ортогональ, стили отображения, опорные элементы, скрыть/изолировать/показать
  всё, наведение и выбор (грань, ребро, точка, плоскость; Shift — добавить, Ctrl — исключить, Esc — снять), закрытое
  телом не выбирается; короткий правый щелчок — общие команды (UI-11).
- Куб вида по образцу 3ds Max (UI-45): грани, рёбра, углы, перетаскивание — вращение, кольцо компаса — вращение вокруг
  вертикали, «Домой», поворот на 90°, стрелки к соседним граням.
- Палитра команд (F): поиск по-русски и по-английски, недавние команды первыми.
- Темы: тёмная и светлая (оболочка, вид, перекраска иконок).

## Проверки

`tests/ui` (Avalonia.Headless, без экрана): реестр команд и иконки, палитра, отмена/повтор, файл и экспорт, выбор
мышью в виде, куб вида, тема. Снимки окна под Xvfb — `--shot файл.png --script "команда;pick:0.5,0.5"`.

## Дальше (UI_AVALONIA_STAGE, п. 6)

U2 — контекстная панель по выбору (таблицы Д/ЭС/Ф/СБ ТЗ_UI), операции детали с предпросмотром и правкой, панель
операции и последней операции; U3 — эскизник; U4 — FreeForm и прямая правка; U5 — сборка; U6 — полировка.
