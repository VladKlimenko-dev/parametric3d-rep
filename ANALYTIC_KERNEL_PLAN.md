# Переход на аналитическое ядро — план и исходный замер (2026-10-06)

## Решение
Форма модели задаётся точными поверхностями (плоскость, цилиндр, конус, сфера, тор, сплайны). Гранение — только
производное: сетка отображения на экране и экспорт в STL/OBJ/3MF. Многогранное точное ядро (plane-based, точная
арифметика) остаётся ЗАПАСНЫМ путём с явным контрактом маршрутов (как у HoleFeature): аналитический маршрут →
при отказе многогранный, с трассой причин. Доля аналитического пути измеряется на корпусе.

Вывод: первый этап (плоскость + квадрики с пересечениями в прямых, окружностях и конических сечениях) покрывает
≈99.7 % пар корпуса; кривые 4-й степени уже есть (IntersectionCurve3, CrossHole) — их подключение вторым этапом.
Плоскость×плоскость многогранное ядро считает точно и так; выигрыш аналитики — в криволинейных парах.

## Этапы
1. **Контракт и каркас аналитической булевой** (маршрут перед многогранным в BooleanOp.Evaluate, трасса решений,
   флаг в снимке контекста): пересечение пар граней из таблицы выше в замкнутом виде (Ssi), разбиение граней кривыми
   пересечения с p-кривыми, классификация кусков «внутри/снаружи» лучом по аналитическому B-rep, сборка тела.
   Проверка: каждый результат — годность (B-rep, сетка), точный объём против многогранного пути и формулы, обмен STEP.
2. **Кривые 4-й степени** через трассировку (IntersectionCurve3), касания и совпадающие поверхности.
3. **Скругления как поверхности** (тор у дуги, цилиндр у прямого ребра, сфера в углу; общий случай — поверхность
   качения шара) — без гранёного резца.
4. **Гранение только для экрана и экспорта**: многогранный путь — запасной; замер его доли на корпусе.

## Что уже есть
Ssi и ExactEdges (точные кривые плоскость/квадрики), IntersectionCurve3, аналитические пути отверстий (QuadricCut,
ExactBoolean, CrossHole, ExactCylinderCut), UvMesher и p-кривые, точный STEP, контракт маршрутов с трассой,
AnalyticVolume (точный объём по поверхностям), TopologyConventions.
