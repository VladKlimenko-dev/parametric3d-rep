# Известные ограничения

1. **Сетки повёрнутых скруглений.** Закрыто в обновлении 4: все 44 сценария A06 и все 88 проверок FProbe rotations (включая обе сетки) годны. Прежняя причина — плоская грань, ставшая несколькими почти совпадающими точными плоскостями (см. CHANGELOG, обновление 4).
2. **Дерево резца у почти выпуклых тел** (сферический вырез) строится цепочкой: O(n²), около 135 мс на сферу из 2 200 граней.
3. **Грань из нескольких областей** делится на грани у плоских граней (по обходу) и, с обновления 19, у кривых — по
   связности треугольников разбиения; кривая грань без треугольников разбиения (не из точной булевой) — не делится.
4. **Выбор полюса шара при чтении IGES** — по габариту остальных граней (эвристика): если обе половины помещаются, поверхность не обрезается.
5. **Вершины трёх поверхностей** не уточняются до точного пересечения (замер: отход 0 на текущем корпусе; у вершин «плоскость–цилиндр» — до 6 мкм от округления сетки).
6. **Кривые пересечения в STEP** — кубический B-сплайн, отклонение ≤ 1e-4 мм (обычно ~2e-5 мм).
7. **Точный объём** не поддержан для смещённых поверхностей, протяжки по произвольной кривой и закрытого тора без края — там объём по сетке с явной границей ошибки.
8. **Воспроизводитель** переносит операнды через STEP: отказ, вызванный кэшем точной формы, а не геометрией, может не повториться (Replay сообщает об этом).
9. **Вершинный переход в непрямом углу** (призма 60°): остаётся угол трёх цилиндров (на 2.45 мм³ материала больше при r = 3); общий резец пробовался, сетка открывалась у торцов цилиндров.
10. **Скругление переменного радиуса**: точно (конус огибающей) для прямого ребра между плоскостями; цепочки и рёбра на кривых гранях идут путём резцов — снятый материал там на ~1.7% больше теоретического для линейного закона.
11. **Лофт между разными сечениями** даёт гранёные грани без аналитической поверхности; протяжка по излому или сплайну — по ломаной.
12. **Решатель эскизов**: линейное решение и ранг плотные — для эскизов в тысячи связных переменных нужна разреженная факторизация.
13. **Правки интерфейса** (`Views/SketchCommands.cs`, `UI/MaterialForm.cs`, `UI/ParametersForm.cs`) в этой среде не компилировались.
14. **Сборка WinForms-приложения** и его проверка в этой среде не выполнялись; ядро и модель проверены отдельными проектами.

## Добавлено в обновлении 3
- Седловые вершины: фаска и скругление вершины не поддержаны.
- Точная булева — только частные случаи (цилиндр минус из тела); общий случай — многогранная булева.
- Точный объём по прослеженным кривым считается ломаной (до 5e-8 относительно).
- Точные рёбра применяются к структурной копии тела при записи STEP, а не в самом теле (расхождение с многогранником следующих операций).
- Разметка в параметрах отдаёт прежнему построителю плоские грани с отверстиями, касающимися края.

## Добавлено в обновлении 4
- Вход «одна плоская грань — одна точная плоскость» (`ExactPlanarInput`) не трогает вершины, лежащие на гранёной кривой грани: они остаются на узле сетки, и плоская грань с такими вершинами может остаться несколькими плоскостями (как прежде).
- Вершина, в которой сходятся больше трёх плоскостей с несовместным пересечением, лишает свои грани их плоскостей (прежний вход для этих граней).
- Плоские грани разных операндов, совпадающие аналитически в пределах 1e-7 мм, получают одну точную плоскость: зазор меньше 1e-7 мм не сохраняется (прежде не сохранялся зазор меньше шага сетки 1e-5 мм).
- Своя плоскость грани резца без контакта — только в общем пути булевой; у резца скругления (TryAttach) её нет: там это ломало 6 сценариев с объединением.
- Решение вершин в `ExactContactInput.TryBuild` и в `ExactPlanarInput` пока продублировано; склейка точек в `TryBuild` — квадратичная (поставка 3).
- Проверочная программа `tests/speed` без аргумента падает (IndexOutOfRange) — так и в обновлении 3.
